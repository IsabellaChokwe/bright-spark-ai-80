# Spark Studio

Build a modern, colorful, mobile-friendly AI Productivity Assistant Dashboard for a student.

Header:
- "AI Productivity Assistant - By Isabella Chokwe | CAPACITI ASA Online" with a clean, branded student vibe and icons.

Layout & Navigation:
- Single page with 3 tabbed tools:
  1. Task Prioritizer:
     - Input to add/paste to-do items.
     - "Prioritize with AI" button that analyzes urgency and categorizes tasks into High (red/rose), Medium (amber/orange), and Low (emerald/green) priority cards with badges, estimated completion times, and reason tags.
     - Interactive checklist to mark tasks complete.
  2. Email Draft Assistant:
     - Input fields: "Who are you emailing?" (e.g. Professor, Internship Recruiter, Group Member), "Key points / what you want to say", and optional tone picker (Formal, Polite & Friendly, Urgent, Follow-up).
     - "Draft Email" AI button with a typing/loading effect.
     - Formatted email output card with Subject line and Body, plus "Copy to Clipboard" and "Regenerate" buttons.
  3. Study Planner:
     - Input fields: Subjects/courses (tags or list), Target exam dates, and daily study hours available.
     - "Generate Study Schedule" AI button.
     - Renders an interactive, weekly study schedule timetable with subjects color-coded, daily focus topics, and break recommendations. Ability to export or print/copy.

General:
- Include built-in realistic mock AI responses with pleasant micro-interactions/loaders so the demo is fully functional immediately.
- Use polished card designs, Lucide icons, smooth tab switching, and vibrant accessible accents.
